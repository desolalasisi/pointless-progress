01

Start with a feeling, not a spec

Prompt (paraphrased)I want a generative series that's pointless, made purely for the sake of making. Scribbles, brush strokes, random shapes.
OutcomeThe brief became "hand-feeling marks". Not pure randomness, but marks with pressure, tremor and hesitation. The palette was fixed from the start.
02

Make the machine behave like a hand

Prompt (paraphrased)It should look like a person made it. Brush strokes, lines and ink marks. Collectors should be able to watch each piece being drawn, and it has to work on a touch screen.
OutcomeA brush made of individual bristles that run dry, pen lines with pressure, deliberate sloppiness, and gestures that get abandoned halfway.
pointless_studio.html · drawBrushSegment()
function drawBrushSegment(s, i) {
  let a = s.pts[i - 1], b = s.pts[i];
  strokeCap(SQUARE);
  for (let br of s.bristles) {
    if (b.t > br.end) continue;          // edge bristles run out first
    let gapLimit = br.dry * (0.15 + b.t * 1.7);
    if (noise(br.ph, i * 0.07) < gapLimit) continue; // gaps open as the brush dries
    let o1 = br.o * s.w * a.p;
    let o2 = br.o * s.w * b.p;
    stroke(br.c);
    strokeWeight(br.th * (0.55 + 0.45 * b.p));
    line(a.x - sin(a.a) * o1, a.y + cos(a.a) * o1,
         b.x - sin(b.a) * o2, b.y + cos(b.a) * o2);
  }
}

What this does: each stroke is a bundle of thin lines instead of one fat one. Drop-out as the stroke progresses is what makes it read as paint rather than a vector line.

pointless_studio.html · maybeAbandon()
// 1 in 5 gestures gets abandoned halfway
function maybeAbandon(pts) {
  if (random() < 0.2)
    return pts.slice(0, max(4, floor(pts.length * random(0.45, 0.85))));
  return pts;
}

What this does: a human hesitates, stops and moves on. A single line of code carries that behaviour.

03

Lock the palette, keep the odds loose

Prompt (paraphrased)White, black, red #FF0000 and yellow #FFAA00 only. I don't want the colours evenly spread. Some marks should mostly be black, with red and yellow arriving as accents.
OutcomeColour is chosen per kind of mark, with different odds for each. Yellow is blocked from thin lines because it disappears on white.

04

Two versions: one to curate, one to show

Prompt (paraphrased)I need to save each piece as a PNG so collectors can mint, but I also want collectors to watch pieces being drawn on my site. Can that be two versions?
OutcomeA studio that renders instantly at export size and lets me keep and review seeds, and a live page that only replays the minted seeds, with no saving. The live page became a window into the 100.
pointless_studio.html · seeded pieces
function startPiece(s) {
  seed = s;
  randomSeed(seed);          // same seed → same piece, every time
  noiseSeed(seed);
  pieceAccent = random() < 0.5 ? COL.red : COL.yellow;
  paintPaper();
  buildGestures();
  ...
}

function renderPiece(s) {
  startPiece(s);
  fastForward();   // studio: no animation, whole piece drawn at once
  noLoop();
  refreshUI();
}

Why it matters: because every piece comes from a number, a minted piece can be reproduced exactly. The live page and the PNG on-chain are the same artwork.

05

Curate 100, then freeze the engine

Prompt (paraphrased)I want to keep the ones I like, step through them, number them, and export the list so I can paste it into the live page.
OutcomeKEEP and REVIEW buttons, numbered PNG export, and a seed list file. The engine version is stamped so nobody changes the drawing code after minting by accident.
pointless_studio.html · exportList()
const ENGINE_VERSION = 'POINTLESS-ENGINE-3';
const EDITION_SIZE = 100;
const EXPORT_DENSITY = 2;   // 2 → 1800 × 2250 px

async function exportList() {
  let js = '// engine ' + ENGINE_VERSION +
           '\nconst MINTED_SEEDS = [' + kept.join(', ') + '];\n';
  let meta = {
    series: 'POINTLESS', engine: ENGINE_VERSION,
    count: kept.length,
    pieces: kept.map((s, i) => ({ number: i + 1, seed: s, file: fileNameFor(s, i + 1) })),
  };
  downloadBlob(new Blob([js]), 'minted_seeds.js');
  downloadBlob(new Blob([JSON.stringify(meta, null, 2)]), 'pointless_metadata.json');
}
06

Let subjects in without losing the hand

Prompt (paraphrased)Introduce other elements into the pieces: portraits, flowers, animals, nature, silhouettes. Not only abstract marks.
OutcomeMotifs drawn with the same careless hand. They are generated after all the original marks, so turning them off reproduces the old pieces exactly.
pointless_studio.html · motifs
const MOTIFS_ON = true;   // false = identical to engine 2
const MOTIF_MIN = 1, MOTIF_MAX = 3;
const MOTIF_WEIGHTS = {
  flower: 3, tulip: 2, branch: 2, tree: 1, butterfly: 1,   // plants
  bird: 2, fish: 1, cat: 1, hare: 1,                         // animals
  face: 3, profile: 2, bust: 2, figure: 1, eye: 1,          // people
  sun: 1, moon: 1, mountains: 1, vine: 1, bloom: 3,       // sky & land
};

// generated AFTER every original gesture, so old seeds keep their marks
if (MOTIFS_ON) buildMotifs(add);

Design decision: an additive layer rather than a rewrite. Existing seeds stay valid and the new material can be switched on or off per piece type.

03 · Decision log

The choices that shaped the series

DecisionWhy
Marks follow rules of a hand, not pure randomPressure, tremor, dry brush and abandoned gestures make it read as a person's work.
Four-colour palette, per-mark oddsKeeps the series cohesive and stops yellow vanishing on white.
Seeds instead of stored imagesEach piece is reproducible, so the live page and the minted PNG are the same work.
Studio and live as separate filesCurating and saving is a private tool; the public page is a window onto the 100.
Engine version stampedAny change to drawing code after minting would change every seed.
Motifs as an additive layerNew subjects without breaking earlier pieces.
Rename to POINT/LESS (Oct 2026)The message stays the same; the identity and promo set are reworked around it.
